Drop your background music here as:

    background.mp3

That exact filename is what src/lib/eventConfig.ts points at
(eventConfig.audio.url = '/audio/background.mp3').

If this folder stays empty, the invitation still works perfectly —
the sound control simply never appears.

Suggestions:
  • keep it under ~2 MB so it does not slow the first load
  • a soft instrumental loop works best
  • make sure you have the right to use the track
